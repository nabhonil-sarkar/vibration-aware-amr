# Repository scope

This repository contains engineering sources and selected generated evidence. It was created as private. Sharing its URL does not grant another person access; collaborator access requires a separate decision.

Academic logbooks, the submitted outline, risk-assessment forms, student identifiers, signatures, contact information, templates, receipts and downloaded reference documents have not been uploaded. Their original local copies are unchanged. Large future raw sensor recordings are excluded from Git by default.

The original project folders remain separate from this working repository. Editing a file in an original folder does not automatically update its repository copy. Make future engineering edits here, or deliberately copy reviewed revisions here before committing. Do not upload the whole academic folder indiscriminately.

No repository-wide open-source licence is added. Existing package metadata is preserved. Choose licensing and any public release only after considering university and third-party requirements.
