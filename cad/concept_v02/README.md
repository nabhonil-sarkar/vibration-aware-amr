# Historical Fusion V2 concept

This folder preserves the earlier complete robot concept, including Fusion and STEP files and balloon-labelled subsystem sheets. It is not a fabrication release.

The current chassis-base revision is in `../chassis_v03`. V2 includes placeholder purchased-part envelopes, a Pi 4 envelope and an older provisional 1500 g parameter; the implementation now has a Pi 5 available and a 1 kg total carried-load target. These historical differences must not be presented as verified current hardware.

The Fusion generator's output path is repository-relative in this copy. Its geometry has not otherwise been revised. It requires the Fusion Python API and must be run inside Fusion, not ordinary Python. Regenerated exports are ignored by Git until deliberately selected for publication.
